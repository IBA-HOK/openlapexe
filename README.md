# OpenLAPexe

MATLAB 版 OpenLAP を Python と Tkinter で再実装したラップタイム・シミュレータです。車両とコースを選んでラップタイムを計算し、速度や加速度をグラフで確認できます。Python 環境があればすぐに起動でき、単一の実行ファイルとして配布することも可能です。

## 特徴

- 車両特性とコース形状からラップタイムを計算
- 市販車からフォーミュラまで対応する車両モデル
- コースの標高、バンク、グリップを考慮したシミュレーション
- 直線加速性能を確認できるドラッグシミュレーション
- OSM 地図や KML / DXF からのコース作成
- シミュレーション結果のグラフ表示と CSV エクスポート
- 依存ライブラリは NumPy のみ

## 必要環境

- Python 3.10 以上
- NumPy 1.26 以上

## インストールと起動

```bash
pip install -r requirements.txt
python main.py
```

`python main.py` でメイン画面が起動します。

単一の実行ファイルを作成する場合:

```bash
pip install pyinstaller
pyinstaller app.spec
```

`dist` フォルダに生成された実行ファイルをダブルクリックで起動できます。

## 使い方

アプリは 5 つのタブで構成されています。

| タブ | 内容 |
|------|------|
| 車両 | 車両諸元を確認・編集します。変更内容は保存して再利用できます。 |
| コース | コース形状を地図上に表示します。区間ごとの距離や特徴も確認できます。 |
| OpenDRAG | 直線加速シミュレーションを実行し、速度や加速度の推移を表とグラフで確認できます。 |
| シミュレーション | 車両とコースを選んでラップタイムを計算します。結果はグラフとタイムで表示され、CSV として保存できます。 |
| 作成 | 新しいコースを作成します。地図上で直接描く方法と、コースの両端から中心線を生成する方法を選べます。KML や DXF からの読み込みにも対応しています。 |

### コースの作成

作成タブでは 2 つの方法でコースを作れます。

- **走行ラインを直接描く**: 地図上をクリックして走行ラインを直接作成します。頂点の追加、削除、ドラッグ移動、やり直しが可能です。
- **コースの両端から生成する**: コースの左右の端を描き、自動で最適な中心線を生成します。

OSM 地図の表示、KML / DXF ファイルの読み込みに対応しています。作成したコースは名前を付けて保存すると、コース一覧に自動で追加され、すぐにシミュレーションに利用できます。

### シミュレーション結果の保存

シミュレーションタブの Export 機能で、結果を CSV ファイルとして保存できます。距離、速度、加速度、ギア、エンジン回転数などが記録され、表計算ソフトなどで分析できます。

## プロジェクト構成

```
main.py              起動用エントリーポイント
app.py               後方互換用のエントリーポイント
app.spec             実行ファイル作成用の設定
src/openlapexe/      本体ソースコード
  vehicle.py         車両モデル
  track.py           コース処理
  solver.py          ラップタイム計算
  drag.py            直線加速シミュレーション
  geo_proj.py        座標変換
  geo_tile.py        地図タイル取得
  curvature_opt.py   コース形状の最適化
  gui/               画面関連
data/vehicles/       車両データ
data/tracks/         コースデータ
tests/               テスト
scripts/             補助スクリプト
```

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| 設定ファイルが破損しているという警告が表示される | 警告を確認すると初期設定で起動します。次回保存時に正常な設定が書き込まれます。 |
| 車両データが読み込めない | 同梱の車両データが破損している可能性があります。リポジトリから `data/vehicles` を再取得してください。 |
| コースが表示されない | `data/tracks` にコースファイルが存在するか確認してください。 |
| 画面が表示されない | Linux 環境でディスプレイが見つからない場合に発生します。`xvfb-run python main.py` で起動できるか確認してください。 |
